■ 4. 補正回収率の完全計算式
================================================================

  【均等払戻方式（Equal Payout Method）】
    全馬券を「的中時に同額（TARGET_PAYOUT = 10,000円）受け取る」
    ように逆算してベット額を決める方式。

    bet_amount[i] = TARGET_PAYOUT / odds[i]
                  = 10,000 / odds（オッズが高いほど少額投資）

  【補正払戻額】
    corrected_payout[i] = TARGET_PAYOUT
                          × correction_coefficient(odds[i], is_fukusho)
                          × is_hit[i]

    ※ is_hit[i] = 1（複勝的中: 着順1〜3着）, 0（着外）

  【期間重み適用】
    weighted_bet[i]    = bet_amount[i]    × year_weight[i]
    weighted_payout[i] = corrected_payout[i] × year_weight[i]

  【補正回収率（最終）】
    補正回収率 = ( Σ weighted_payout[i] / Σ weighted_bet[i] ) × 100
              = ( Σ[correction × is_hit × year_weight]
                / Σ[1/odds × year_weight] ) × 100

  【スコア（ベースライン差分）】
    score = 補正回収率 - 80.0
    score > 0 → 市場平均（80%）を上回る → エッジあり
    score < 0 → 市場平均以下

  実装場所: backend/engine/corrected_return.py
            calc_corrected_return_rate()

■ 5. 信頼度
================================================================

  信頼度 = √( N / (N + 400) )

  N = ビン内サンプル数（該当する出走馬の総数）

  ┌────────────────────────────────┐
  │   N    │  信頼度  │ 意味       │
  ├────────────────────────────────┤
  │    30  │  0.267  │ 低信頼     │
  │   100  │  0.447  │ 参考値     │
  │   400  │  0.707  │ 中信頼     │
  │  1,600 │  0.894  │ 高信頼     │
  │  9,600 │  0.980  │ 非常に高い │
  │ 40,000 │  0.990  │ ほぼ確実   │
  └────────────────────────────────┘

  実装場所: factor_screening.py: confidence = math.sqrt(n / (n + 400))

■ 6. ビン評価基準（factor_adoption.py）
================================================================

  有効ビン条件: n >= 100（100サンプル未満のビンは除外）
  有効ビン数 < 3 → 判定不能

  採用判定:
    pass_rate = (place_roi >= 80% のビン数) / (有効ビン数)

    pass_rate >= 0.50  → 採用
    pass_rate >= 0.30  → 検討
    pass_rate < 0.30   → 不採用

■ 7. 現状の実装とのズレ（要修正箇所）
================================================================

  【3段階の乖離が判明している】

  ┌───────────────────────────────────────────────────────────────┐
  │ スクリプト          │ ROI種別       │ 108段補正 │ 期間重み │
  ├───────────────────────────────────────────────────────────────┤
  │ factor_screening.py │ 重み付き平均  │    ❌    │    ✅    │
  │ factor_adoption.py  │ 重み付き平均  │    ❌    │    ✅    │
  │ analysis_engine.py  │ 補正回収率    │    ✅    │    ✅    │ ← 正規
  │ factor_investment   │ 単純平均      │    ❌    │    ❌    │ ← 要修正
  │ _screening.py       │               │          │          │
  └───────────────────────────────────────────────────────────────┘

  factor_screening.py / factor_adoption.py が使う place_roi:
    place_roi = Σ(haraimodoshi_fukusho × year_weight)
                / (Σyear_weight × 100) × 100
    → 「期間重み付き払戻平均」であり、補正係数なし。
    → CLAUDE.md規約の完全な「補正回収率」とは異なる。

  factor_investment_screening.py が使う mean_place_roi:
    mean_place_roi = mean(haraimodoshi_fukusho)
    → 生払戻の単純平均。補正なし、重み付けなし。
    → 最もCLAUDE.md規約から遠い実装。

  【正しい補正回収率の計算ルート】
    corrected_return.py: calc_corrected_return_rate()
    使用場所: analysis_engine.py のみ（フロントエンド向け単体分析）

  【影響範囲】
    - filter_screening.py で採用された1,390件のファクターは
      「期間重み付き払戻平均 >= 80% が過半数」という基準で選ばれており、
      真の補正回収率ベースでは異なる結果になる可能性がある。
    - investment_screening.py の CLB（保守的回収率）は
      生払戻ベースであるため、補正回収率ベースと比較不可。

■ 8. 推奨修正方針
================================================================

  【Phase A: factor_investment_screening.py の即時修正】
    get_valid_bin_bets() の返り値を
      haraimodoshi_fukusho の生値 → 補正払戻 に変更

    具体的計算:
      corrected_payout[i] = TARGET_PAYOUT * correction(odds[i]) * is_hit[i]
      bet_amount[i]        = TARGET_PAYOUT / odds[i]
      weighted_ratio[i]    = (corrected_payout[i] / bet_amount[i]) * year_weight[i]

    ただし CLB の計算では個票分散が大きい問題は残る（→ 閾値校正が必要）

  【Phase B: factor_screening.py の中長期修正】
    _bin_stats() の place_roi を corrected_return.py 方式に統一。
    ただし 456,615行 × ビン評価で処理時間が大幅増加（現状6時間 → 推定10時間超）
    → 段階的移行が現実的。

  【Phase C: 採用基準の再定義】
    補正回収率 >= 80%（score >= 0）を採用基準とし、
    factor_adoption.py の pass_rate 判定と統合。

■ 9. CLB（保守的回収率下限）の定義
================================================================

  CLB = mean - 1.96 × std / sqrt(N)

  ここで:
    mean = ビン内補正回収率の平均（正規実装では補正払戻/ベット額）
    std  = ビン内の分散
    N    = 有効ベット数
    1.96 = 95%信頼区間の正規分布係数

  【現状の投資スクリーニングでの CLB】
    N   = 全有効ビンのベット数プール
    mean/std = haraimodoshi_fukusho の生統計量（補正なし）

  【理想的な CLB】
    ビン単位の補正回収率を算出し、
    そのビン間分散から CLB を求める方式（集計レベルCLB）が
    個票レベルよりも安定した推定値を与える可能性がある。
